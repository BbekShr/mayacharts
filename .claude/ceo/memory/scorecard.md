not activity. The CEO updates earlier rows' outcomes in preflight. Promotion criteria live in
`.claude/ceo/AUTONOMY.md`.

was merged by the owner, none was reverted. Human edits before merge can't be told apart in git
(owner and agent commit as the same user), so those rows say `unknown`; from now on the CEO
records them. Promotion to L2 also needs `/org-eval` scores, which start with this adoption.
