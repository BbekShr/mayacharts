## notes_for_human

Cuts that need your call, largest first:

- **HINTS text in validate.ts**: about 520 B gzip across all entries; every entry is asserted by tests. Keep the hints for the most common mistakes only?
- **en-US fast number path in format.ts**: about 200 B. It skips the ICU load (about 7 ms first format); a test pins it.
- **`light-dark()` fallback in theme.ts**: about 100 B in theme, index and global each. Only matters on Chrome below 123, Safari below 17.5 and Firefox below 120, where 11 other `light-dark()` uses already fail, so the fallback only half works there. Dropping it sets that as the browser floor.
