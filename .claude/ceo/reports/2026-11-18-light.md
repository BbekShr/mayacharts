## First principles

1. **What did we learn?** A formatted string is the number plus its affixes. Any edit to "the sign" must be anchored to the number, and applied only when the value says a sign is there.
2. **What are the foundations?** Formatting is one-way, as on 2026-11-05. The value itself (`v < 0`) is the only trusted fact about the string; position and first match are not. For dates, Intl treats `dateStyle` and field options as exclusive, so adding one field means giving up the style.
3. **Can it do more than this?** kpi and gauge make the same first-hyphen swap (filed). Any future glyph swap in `ctx.fmt` output should go through one anchored helper if a third mark needs it.
4. **How far can it go?** The anchor fails when a prefix holds a hyphen followed by a digit, and BC detection fails across a host `timeZone` at the year 1 boundary. Both are recorded ceilings.
