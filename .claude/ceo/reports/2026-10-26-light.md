## First principles

1. What did we learn? With every bundle at 98 to 99% of budget, the cheapest real improvements are in the site, the docs and string composition, not in new drawing code. Headroom, not ideas, now sets the pace.
2. Foundations: a change stated in points and a change stated in percent of the old value are two encodings of one move; showing both on a percent measure doubles the line for no new information.
3. Can it do more? kpi.ts has the same pts plus percent line (it drops the parenthetical only when narrow). Backlogged; it touches core.
4. How far can it go? The regex assumes the default or a translated template keeps the percent as the first parenthetical; an override that puts a parenthesis earlier would lose the wrong part. Noted in the strings docs.
