## First principles

1. **What did we learn?** A localised template owns token order. Code that finds a token by position in the formatted output silently breaks for every locale that reorders it.
2. **What are the foundations?** Formatting is a one-way function. The only reliable way to locate a substituted value afterwards is to carry the value itself, or its offset, out of the substitution.
3. **Can it do more than this?** Every `ctx.t()` call whose output is split later is a candidate. Today only kpi splits one; gauge builds its change line the same way and should be checked if it ever tones a part.
4. **How far can it go?** `indexOf` breaks when a substituted label contains the same glyph (filed). An offset returned from `t()` would close it, at a cost in every template call.
