## Process incident

A worktree editor's commit (82bd4fb) included a `node_modules` symlink, because `.gitignore` had `node_modules/`, which matches directories only. Merging it replaced the main tree's real `node_modules` with a symlink to itself, which broke every worktree for about a minute. Fixed by 04b72f8 (untrack) and f14c5b3 (`node_modules` without the slash), then `npm ci`. The commit is still in the branch history; a squash merge removes it. Editors now run `npm ci` in their worktree (learnings).
