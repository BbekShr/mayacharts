Errors

Every mayaCharts error links here. Each section explains the code and shows a fix.

Back to examples

spec-not-object

The spec must be a plain JSON object. You passed something else, such as a string, array, null or undefined. A common cause is passing the raw JSON text instead of parsing it. 

el.spec = JSON.parse(text); // not the string itself

missing-field

Every spec needs the four fields type, data, x and y. One of them is absent.

{ "type": "bar", "x": "month", "y": "revenue",
  "data": [{ "month": "Jan", "revenue": 12 }] }

unknown-type

spec.type must be one of bar, line or area. The message suggests the closest match when there is one. 

{ "type": "bar", ... }

data-not-array

spec.data must be an array of row objects. An object keyed by category, or a JSON string, is not accepted. 

data: Object.entries(totals).map(([month, revenue]) => ({ month, revenue }))

row-not-object

Every entry in spec.data must be a plain object. Arrays, numbers and null rows are rejected; the message names the index. 

data: [{ "month": "Jan", "revenue": 12 }]   // not [["Jan", 12]]

unknown-field

spec.x, spec.y or spec.series names a field that no row has. The message lists the fields found in your data. Check spelling and case. 

// rows have "month" and "revenue"
{ "x": "month", "y": "revenue" }

non-numeric-y

The y field must hold finite numbers. null and undefined are allowed and draw a gap. Numeric strings are rejected, so convert them first. 

data.map(r => ({ ...r, revenue: Number(r.revenue) }))

unknown-option

The spec has a top-level key that mayaCharts does not know. The message suggests the closest known option. Typos such as "stacked" instead of "stack" land here. 

{ "stack": true }   // not "stacked"

invalid-option

A known option has the wrong type, for example a string where a boolean is expected, or colors that is not an array of strings. 

{ "legend": true, "colors": ["#2563eb", "#f97316"] }

stack-unsupported

Stacking is not defined for line charts. Use an area chart or a bar chart to stack series. 

{ "type": "area", "stack": true, ... }

invalid-domain

spec.yDomain must be [min, max] with two finite numbers and min less than max.

{ "yDomain": [0, 100] }

invalid-format

spec.yFormat must be one of auto, compact, percent or currency. Formatting is preset-based because the spec is plain JSON and cannot hold functions. 

{ "yFormat": "compact" }

invalid-theme

spec.theme contains a key that is not a theme token. Valid tokens are font, fontSize, fg, fgMuted, grid, bg, accent, radius, tooltipBg, tooltipFg and focus. 

{ "theme": { "accent": "#7c3aed" } }

unsafe-css-value

Theme and color values are written into CSS custom properties, so they must be plain CSS values. Characters such as ; { } < > \ and url( or expression( are rejected. 

{ "colors": ["#2563eb", "rgb(249 115 22)"] }

invalid-size

The width and height render options must be finite numbers greater than zero.

renderShell(spec, { width: 760, height: 320 })
